# UI UX Pro Max — solo instalación

Esta skill **no se incluye en el repositorio** porque el paquete oficial depende de datos y scripts que el CLI mantiene actualizados.

| Campo | Valor |
| --- | --- |
| **Origen** | https://github.com/nextlevelbuilder/ui-ux-pro-max-skill |
| **Autor** | Next Level Builder |
| **Licencia** | MIT (ver repositorio upstream) |
| **Instalación** | Ejecutada por `install.sh` / `install.ps1` |

```bash
npm install -g ui-ux-pro-max-cli
uipro init --ai cursor
```

Tras instalar, la skill quedará en `~/.cursor/skills/` (o la ruta que indique el CLI).
